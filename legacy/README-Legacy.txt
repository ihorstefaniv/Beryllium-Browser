Beryll Legacy — сучасний браузер для Windows 7 / 8 / 8.1 на слабких ПК
=======================================================================

ЯК ЗАПУСТИТИ
1. Розпакуйте архів повністю (наприклад, у C:\Beryll або на флешку).
   Не запускайте прямо з архіву.
2. Запустіть Beryll.exe. При першому запуску Beryll запропонує створити ярлик.

Нічого встановлювати не треба: .NET 3.5, потрібний оболонці, уже є у Windows 7.
Закладки, паролі й історія лежать у папці profile поруч із програмою.
Паролі зашифровані для вашого облікового запису Windows: на іншому ПК їх не прочитати.

ЩО ВСЕРЕДИНІ
- Рушій Supermium (сучасний Chromium для старих Windows): працюють Gmail, YouTube,
  сучасні сайти й відеоплеєри, HTTPS не залежить від застарілих сертифікатів Windows 7.
- Блокувальник реклами uBlock Origin.
- Пошук DuckDuckGo, без звернень до Google, Do Not Track і Global Privacy Control.
- «Легке відео (H.264)»: YouTube віддає відео у форматі, який старий ПК декодує
  найлегше. Перемикач унизу сторінки нової вкладки.
- Підлаштування під залізо: на ПК з 2 ГБ пам'яті вмикається економний режим.

ПОРАДИ ДЛЯ СЛАБКОГО ПК (Atom, 2 ГБ, HDD)
- YouTube: якість 360p–480p (шестерня у плеєрі). 720p на Atom може йти ривками.
- Тримайте відкритими 3–5 вкладок.
